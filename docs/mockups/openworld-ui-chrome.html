openworld · Android · UI chrome

Chrome laid over the map

Five screens. Every control is printed onto the map rather than floated above it in Material style: ivory medallions, ink rules and wax-seal compass points. Tap inside the phone to move through the flow, or pick a screen below.

    Touch. Every target is 48dp or more. Map medallions are 52dp. Close, inspect and settings actions sit in the bottom sheet, within thumb reach.

    Contrast. Chrome uses an ivory fill, a 1.5px ink edge and a soft shadow, so it holds up against the busy backdrop. The compass seals use ivory letters on ink.

    Placeholder data. Biome names, coordinates and the seed are example values.
